## بناء APK عبر GitHub Actions
1. أنشئ مستودعاً جديداً في GitHub.
2. ارفع كل محتويات هذا المجلد إلى المستودع (حافظ على أسماء المجلدات).
3. افتح تبويب Actions وفعّله إذا طلب ذلك.
4. شغّل workflow **Build KhudarnaStore APK**.
5. بعد نجاح البناء، نزّل الملف من Artifacts (store-debug-apk).

**ملاحظة مهمة لنشره على Google Play:** هذا الإجراء ينتج APK تجريبي (debug) للاختبار فقط.
للنشر على المتجر تحتاج:
- حساب Google Play Console (رسوم تسجيل لمرة واحدة).
- بناء نسخة Release موقّعة (Signed AAB) بمفتاح توقيع خاص بك — غير مشمول هنا لأسباب أمنية (يجب أن يبقى مفتاح التوقيع سرياً وليس بمستودع عام).
- سياسة خصوصية، وصف للتطبيق، لقطات شاشة.
